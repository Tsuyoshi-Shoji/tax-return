# 青色申告対応 収益・支出分類・仕訳業務ルール

- 文書ID: BR-ACCOUNTING-001
- バージョン: 1.1
- 対象: 個人事業主（主にフリーランスエンジニア）
- 会計方式: 発生主義・複式簿記（青色申告決算書／貸借対照表対応）
- 対象年度: 2026年以降を想定。税制改正時は年度別設定を確認すること。
- 状態: 実装用仕様案（税務上の個別判定は税理士等への確認を推奨）

> **適用優先順位:** 第11〜15章は追加合意した運用方針を定義し、既存章の例示・初期値と矛盾する場合は第11〜15章を優先する。既存の全選択肢マッピングは維持する。

## 1. 目的・基本原則

本仕様は、画面上の「収益／支出 → 区分 → 選択肢」を会計上の勘定科目と仕訳に変換し、仕訳帳、総勘定元帳、損益計算書（P/L）、貸借対照表（B/S）、青色申告決算書の作成に利用する。

1. **UI区分と会計区分を混同しない。** 画面の「収益」は入金イベント、「支出」は出金イベントを含み、必ずしも収益・費用ではない。
2. 会計上の大区分は `ASSET（資産）`、`LIABILITY（負債）`、`EQUITY（純資産）`、`REVENUE（収益）`、`EXPENSE（費用）` の5つ。`事業主貸`・`事業主借` は個人事業特有のB/S科目として別コードを保持し、決算時に元入金との関係を処理する。
3. 仕訳は必ず借方合計＝貸方合計。入力イベント1件から複数行仕訳を生成できる。
4. 売上・経費の計上時点と入出金時点を区別する（売掛金、未収入金、買掛金、未払金など）。二重計上禁止。
5. 「申告対象外」は原則として**事業所得の損益集計から除外する**意味とし、事業用口座での資金移動そのものを帳簿から削除する意味ではない。
6. 家事按分は事業使用割合のみ費用化し、私用部分は原則 `事業主貸` に振り替える。割合は根拠を記録する。
7. 消費税の税込／税抜経理方式、課税事業者／免税事業者、インボイス・税区分は所得税の勘定科目分類とは別に管理する。
8. 所得控除（国民年金、国民健康保険等）は原則として事業の必要経費ではなく、確定申告書の所得控除データに連携する。

## 2. マスターデータ設計

### 2.1 推奨データ構造

```text
transaction
  id, transaction_type(INCOME|OUTGO|TRANSFER|ADJUSTMENT)
  ui_category, ui_item, event_date, accounting_date
  gross_amount, tax_amount, tax_code, tax_method
  payment_method, settlement_account_id
  counterparty, description, evidence_id
  business_use_ratio, business_use_basis
  excluded_from_business_pl, exclusion_reason
  status(DRAFT|POSTED|REVERSED)
  related_transaction_id, receivable_payable_id
  asset_id, loan_id, advance_id, deposit_id

journal_entry
  id, source_transaction_id, posting_date, fiscal_year
  reversal_of_entry_id, status

journal_line
  entry_id, line_no, debit_credit(D|C)
  account_code, amount, tax_code, subaccount_code

account_master
  code, name, accounting_class, statement_section
  normal_balance, enabled, effective_from, effective_to

ui_item_mapping
  ui_category, ui_item, default_account_code
  classification_rule_id, requires_review, effective_from
```

`transaction` は業務イベント、`journal_entry/journal_line` は確定仕訳。画面の選択肢を直接P/Lへ加算しない。

### 2.2 基本勘定科目

| 大区分 | 主要科目 | 決算書上の扱い |
|---|---|---|
| REVENUE | 売上高、雑収入 | P/L |
| EXPENSE | 仕入高、租税公課、荷造運賃、水道光熱費、旅費交通費、通信費、広告宣伝費、接待交際費、損害保険料、修繕費、消耗品費、減価償却費、福利厚生費、給料賃金、外注工賃、利子割引料、地代家賃、支払手数料、新聞図書費、研修費、諸会費、雑費等 | P/L。決算書の既定欄にない補助科目は「その他の経費」等に集約 |
| ASSET | 現金、普通預金、売掛金、未収入金、立替金、前払費用、長期前払費用、商品、貯蔵品、工具器具備品、車両運搬具、ソフトウェア、敷金・保証金、仮払金 | B/S |
| LIABILITY | 買掛金、未払金、未払費用、借入金、預り金、前受金、仮受金 | B/S |
| EQUITY相当 | 元入金、事業主貸、事業主借 | B/S（事業主貸・借は独立管理） |

※ 具体的な決算書表示欄への対応は年度・様式別の `statement_mapping` に持たせる。帳簿の科目名と決算書の印字項目が必ずしも一致するとは限らない。

## 3. 収益選択肢の分類マッピング

### 3.1 売上

下表の全項目は原則 `REVENUE / 売上高`。業務別の内訳は補助科目・売上種別として保持する。

| 画面選択肢 | 大区分 | 既定勘定科目 | 判定・補足 |
|---|---|---|---|
| SES・準委任契約報酬 | REVENUE | 売上高 | 契約・検収・役務提供実態に応じて計上 |
| 受託システム開発 | REVENUE | 売上高 | 検収条件、進捗計上等は契約内容に応じて判定 |
| IT講師・技術研修 | REVENUE | 売上高 | 事業として提供する講師役務 |
| 技術記事・コンテンツ制作 | REVENUE | 売上高 | 事業としての制作報酬 |
| 自社サービス・SaaS利用料 | REVENUE | 売上高 | 前受期間がある場合は前受金・期間配分を検討 |
| ソフトウェア・ライセンス販売 | REVENUE | 売上高 | 販売契約の実態で収益認識 |
| 広告・アフィリエイト収益 | REVENUE | 売上高 | 継続的な事業収益の場合。単発・事業外なら要判定 |
| その他売上 | REVENUE | 売上高 | 内容必須、科目の妥当性を確認 |

標準仕訳：売上計上 `借方 売掛金 / 貸方 売上高`、入金 `借方 普通預金 / 貸方 売掛金`。即時入金なら `借方 普通預金 / 貸方 売上高`。源泉徴収のある報酬は入金差額を売上値引きにせず、事業主貸等の適切な補助管理と所得税申告データへ連携する（例：売掛金100、普通預金90、源泉徴収税額10）。

### 3.2 雑収入

| 画面選択肢 | 大区分 | 既定勘定科目 | 条件・例外 |
|---|---|---|---|
| 補助金・助成金（事業関連） | REVENUE | 雑収入 | 交付条件・確定時点・非課税等の特例を個別確認。事業所得に帰属しない給付は別管理 |
| 事業関連の保険金・補償金 | REVENUE（条件付き） | 雑収入 | 逸失利益・経費補填等は収益候補。固定資産損害の補償や非課税扱い等は個別判定 |
| 取引先からの謝礼金 | REVENUE | 雑収入 | 本業の対価なら売上高に変更 |
| 事業関連のキャッシュバック | REVENUE（条件付き） | 雑収入 | 値引き・仕入割戻・経費返還の性質なら原取引の減額処理を優先 |
| 事業関連の雑収益 | REVENUE | 雑収入 | 事業所得に該当することを確認 |
| その他雑収入 | REVENUE（条件付き） | 雑収入 | 内容必須。事業外所得や非課税取引を自動で雑収入にしない |

### 3.3 その他（入金だが原則売上ではない）

| 画面選択肢 | 大区分 | 既定仕訳（借方 / 貸方） | 必須条件 |
|---|---|---|---|
| 事業主借入金（事業主借） | EQUITY相当 | 普通預金 / 事業主借 | 個人資金の事業投入。第三者借入と区別 |
| 借入金入金 | LIABILITY | 普通預金 / 借入金 | 貸主、契約、返済条件、元本を登録 |
| 預り金の受入 | LIABILITY | 普通預金 / 預り金 | 第三者へ返す義務のある金銭。顧客前受金なら前受金 |
| 立替金の回収 | ASSETの減少 | 普通預金 / 立替金 | 元の立替金債権と紐付け。自分の経費の reimbursement は別判定 |
| 誤入金・返金調整 | 条件付き | 普通預金 / 仮受金、または原仕訳の反対仕訳 | 誤入金は仮受金等、返金は原取引に連動。収益化しない |
| その他の資金移動 | 条件付き | 振替先資産 / 振替元資産等 | 内容・相手科目必須。既定で売上計上禁止 |

### 4.2 仕入

| 画面選択肢 | 大区分 | 既定勘定科目 | 条件 |
|---|---|---|---|
| 商品仕入 | EXPENSE / 棚卸連携 | 仕入高 | 再販売用。期末未販売分は棚卸資産へ反映 |
| ソフトウェア仕入 | EXPENSE / 棚卸連携 | 仕入高 | 再販売用ライセンス等。自社利用はソフトウェア等 |
| ハードウェア仕入 | EXPENSE / 棚卸連携 | 仕入高 | 再販売用。自社使用は消耗品費・固定資産等 |
| 販売用デジタルコンテンツ仕入 | EXPENSE / 棚卸連携 | 仕入高 | 販売用権利・制作物の実態により棚卸・無形資産等を判定 |
| 原材料・部品仕入 | EXPENSE / 棚卸連携 | 仕入高 | 製造原価・仕掛品の管理が必要な場合は別途原価管理 |
| その他仕入 | EXPENSE / 棚卸連携 | 仕入高 | 仕入対象・販売目的を必須入力 |

仕入時 `借方 仕入高 / 貸方 買掛金`、支払時 `借方 買掛金 / 貸方 普通預金`。期末には棚卸を行い、売上原価 = 期首棚卸高 + 当期仕入高 − 期末棚卸高 を反映。仕入と外注費を混同しない。

### 4.3 その他（出金だが原則経費ではない）

| 画面選択肢 | 大区分 | 既定仕訳（借方 / 貸方） | 条件 |
|---|---|---|---|
| 生活費 | EQUITY相当 | 事業主貸 / 普通預金 | 私的支出。必要経費にしない |
| 娯楽費 | EQUITY相当 | 事業主貸 / 普通預金 | 私的娯楽。事業接待は別区分へ変更 |
| 所得税・住民税の納付 | EQUITY相当 | 事業主貸 / 普通預金 | 原則必要経費にしない。税額申告管理と連携 |
| 国民健康保険・国民年金 | EQUITY相当 | 事業主貸 / 普通預金 | 事業経費ではない。支払者・対象者・支払年を所得控除台帳に連携 |
| 借入金元本返済 | LIABILITYの減少 | 借入金 / 普通預金 | 元本のみ。利息は別仕訳 |
| 固定資産購入 | ASSET | 工具器具備品等 / 普通預金 | 資産種別・取得日・耐用年数・償却方法を記録 |
| 前払費用 | ASSET | 前払費用 / 普通預金 | 対象期間に応じ費用振替。短期前払費用の特例は別途要件判定 |
| 敷金・保証金 | ASSET | 敷金・保証金 / 普通預金 | 返還されない償却部分は別処理 |
| 立替金の支払い | ASSET | 立替金 / 普通預金 | 第三者のための一時立替。事業主自身の経費と区別 |
| 預り金の支払い | LIABILITYの減少 | 預り金 / 普通預金 | 元の預り金残高と紐付け |
| 誤出金・返金処理 | 条件付き | 仮払金 / 普通預金、または原仕訳の反対仕訳 | 誤出金と売上返金・経費返金を区別 |
| その他資金移動 | 条件付き | 振替先科目 / 振替元科目 | 口座間振替・現金引出し等。相手科目必須 |

## 5. 自動仕訳ルール

### 5.1 決済方法と貸方・借方

| 決済方法 | 支出時の既定貸方 | 収入時の既定借方 | 備考 |
|---|---|---|---|
| 現金 | 現金 | 現金 | 事業用現金を使用した場合 |
| 銀行振込 | 普通預金 | 普通預金 | 口座ID必須 |
| クレジットカード | 未払金 | 原則未収入金等（取引実態で判定） | 利用時に未払金、引落時に `未払金 / 普通預金`。カード売上は加盟店債権等を判定 |
| 電子決済 | 決済口座資産または未払金 | 決済口座資産または未収入金 | プリペイド・後払い・決済事業者預りで分岐 |
| その他 | 手動指定 | 手動指定 | 相手勘定必須 |

**重要:** 私用クレジットカードで事業経費を立て替えた場合は `借方 経費 / 貸方 事業主借` が基本。事業用カードと区別する。売掛金・買掛金・未払金をすでに計上済みなら、決済時はその消込のみを行う。

### 5.2 家事按分

- `business_use_ratio` は 0〜100%、根拠・適用期間を記録。
- 事業用資金から税込10,000円を支払い、事業割合20%の場合（説明用・税込経理）：`借方 水道光熱費 2,000 / 借方 事業主貸 8,000 / 貸方 普通預金 10,000`。
- 私用資金で全額を支払った場合：`借方 水道光熱費 2,000 / 貸方 事業主借 2,000`。私用分8,000円を事業帳簿に計上しない。
- 既定按分率は利用者設定とし、電気・ガス・水道・家賃・通信・車両等を個別管理。**20%等の固定値を税法上の一律基準として扱わない。**
- 家事按分不可・根拠不足の項目はレビュー状態へ。

### 5.3 固定資産・減価償却

1. 取得時に「事業用途」「取得価額」「取得日」「資産種別」「使用開始日」「事業使用割合」を確認。
2. 原則、使用可能期間が1年以上かつ取得価額が10万円以上のものは固定資産処理を検討。10万円未満または使用可能期間1年未満は、一定の要件で消耗品費等とできる。
3. 10万円以上20万円未満の一括償却資産、青色申告者の少額減価償却資産特例等は、**対象年度の法令・適用要件・上限・申告書記載要件**を確認して選択可能にする。金額だけで無条件に即時費用化しない。
4. 事業用割合、償却方法、耐用年数、期中取得、除却・売却を資産台帳で管理。
5. 減価償却費は通常、手入力ではなく資産台帳から計算し決算仕訳へ連携。資産売却収入を機械的に事業売上・雑収入に分類しない（所得区分判定）。

### 5.4 源泉徴収・消費税

- 売上に係る源泉徴収は、報酬の種類と支払者等により要否が異なる。**SES・開発報酬だから一律源泉徴収対象、とはしない。** 源泉徴収前の総額で売上計上し、差引税額は別管理する。
- 税理士・弁護士等への支払や給与支払の源泉徴収義務は、支払者の属性・報酬の種類により別判定する。
- 消費税は課税売上、非課税、不課税、免税、課税仕入等の区分と適用税率を保持。海外SaaS・海外サービス、インボイス未登録事業者からの仕入れは個別判定。
- 税抜経理なら仮受消費税・仮払消費税等を使用。税込経理なら原則税込金額で計上。免税事業者の取扱いは適用年度の制度に従う。

### 5.5 返金・取消・誤入出金

- 返金は `refund_of_transaction_id` で原取引に紐付け、売上取消、売上値引、仕入返品、経費返還、仮受金返還等を分類。
- 確定済仕訳を物理削除せず、逆仕訳または訂正仕訳を記録。操作履歴・日時・操作者を保存。
- 未特定の誤入金は仮受金、誤出金は仮払金等で一時管理し、確定時に振替。未特定のまま自動で雑収入・雑費にしない。

## 7. 決算・申告書集計ルール

- **P/L:** 売上高、雑収入、売上原価、必要経費、青色申告特別控除前の所得金額を集計。控除額は適用要件に応じ別計算。
- **B/S:** 期末現預金、売掛金、棚卸資産、固定資産、未払金、借入金、預り金、元入金、事業主貸・事業主借等を集計。
- **青色申告特別控除:** 65万円・55万円・10万円の区分は、複式簿記、期限内申告、貸借対照表添付、e-Taxまたは電子帳簿保存等の**適用年度の要件**で判定。控除は帳簿上の経費科目にしない。
- **所得控除:** 国保・国民年金・生命保険料等は別台帳に記録し、控除要件を確認して確定申告書へ連携。
- **所得税・住民税:** 事業の必要経費に含めない。個人の所得税申告と納付情報を区別する。
- **年次繰越:** 資産・負債と元入金・事業主勘定を所定の個人事業の期首処理で繰越。損益科目は翌年へ残高繰越しない。
- **証憑:** 請求書、領収書、カード明細、契約書等を取引・仕訳に関連付け、法令上必要な保存期間・電子取引データ保存要件に従う。

## 10. 実装時の決定事項

1. 初期勘定科目名は本書を既定とし、利用者が補助科目を追加できるようにする。
2. `ui_item_mapping` は固定文字列によるハードコードではなく、変更履歴のあるマスタとして保持する。

5. この文書は会計アプリの業務仕様であり、個別の税務判断を自動的に保証するものではない。制度改正や特殊取引は年度別ルールの改訂対象とする。


## 11. 発生日中心の簡易登録・例外的な債権債務管理（追加合意）

- 会計基準は**発生主義**。`event_date` は役務提供・納品・利用・資産取得等の実態に基づく計上日であり、単なる入力日・請求日・入出金日と同義ではない。
- 運用上は発生日と決済日が一致する取引が大半であることを想定し、通常登録の既定値を `settlement_status=SETTLED`、`settlement_date=event_date` とする。ただし**決済済みと確認できる場合に限る**。未確認なら決済済みにしない。
- 売掛金・未収入金・買掛金・未払金・未払費用・前受金は削除しない。発生日と決済日が異なる場合に自動計上し、後日消し込む。未決済残高を年末に持ち越せること。
- 売上や経費の登録と入出金の登録で**二重計上しない**。決済イベントは債権債務の消込仕訳のみを生成する。
- 決済状態は `UNSETTLED / PARTIALLY_SETTLED / SETTLED`。分割入金・分割支払と残高照合を許容する。
- 事業用クレジットカードは利用日と口座引落日を区別し、原則として利用時 `経費等 / 未払金`、引落時 `未払金 / 普通預金`。個人カードでの事業費立替は原則 `経費等 / 事業主借`。支払方法だけで決済完了とみなさない。
- 借入金・固定資産・減価償却・前払費用等は金銭の出入りと損益計上が一致しないため、専用台帳・期間配分処理を用いる。

## 12. 事業主貸・事業主借と申告控除の完全分離（追加合意）

### 12.1 絶対原則

1. `事業主貸` と `事業主借` は**売上高を増減させず、必要経費にも算入しない**。B/S・元入金関連の管理に用いる。
2. **所得控除は売上高から直接差し引かない。** 売上高から必要経費等を計算して事業所得を確定した後、他の所得との合算・損益通算等を経て、所得控除を別工程で適用する。
3. 事業主貸に計上したことだけでは所得控除は確定しない。控除候補の登録、支払事実・適格性の確認、控除額計算、申告への反映を別々に行う。
4. 事業用口座からの私的支出は `事業主貸 / 普通預金`。**個人口座のみで完結した私的支出**は事業帳簿へ無理に仕訳せず、申告控除台帳に直接登録できる。
5. 事業用の損害保険料と、私用の生命保険料・地震保険料を混同しない。私用保険は要件に応じて所得控除候補とし、事業用保険は必要経費・資産計上・按分を判定する。二重控除は禁止。

### 12.2 税金・保険料の判定マトリクス

| 入力内容・性質 | 事業口座支払時の原則借方 | 事業P/L | 後日申告処理 |
|---|---|---|---|
| 国民健康保険料・国民年金保険料 | 事業主貸 | 影響なし | 社会保険料控除候補（原則実際に支払った年、支払者等を確認） |
| 国民年金基金・小規模企業共済掛金 | 事業主貸 | 影響なし | それぞれ適切な所得控除区分で判定 |
| 個人の生命保険料・介護医療保険料 | 事業主貸 | 影響なし | 生命保険料控除候補、限度額・区分を適用 |
| 個人の地震保険料 | 事業主貸 | 影響なし | 地震保険料控除候補、要件・限度額を適用 |
| 個人の所得税・住民税 | 事業主貸 | 影響なし | 原則として所得控除・必要経費の対象外。源泉徴収税額・予定納税等は別途税額精算管理 |
| 事業用の損害保険料 | 損害保険料等 | 必要経費候補 | 事業割合・対象期間・積立部分を判定。所得控除と重複不可 |
| 個人事業税、事業用固定資産税、事業用印紙税等 | 租税公課 | 必要経費候補 | 税目・用途・計上時期を確認 |
| 個人の固定資産税（私用部分） | 事業主貸 | 影響なし | 原則対象外。事業使用部分は合理的按分を検討 |
| 消費税納付 | 税込/税抜経理に応じた科目 | 条件による | 消費税経理方式・申告状況による。単純に全額事業主貸にしない |
| 罰金・加算税・延滞税等 | 原則事業主貸等 | 原則必要経費外 | 税目・法的性質を個別判定 |

- UIの `租税公課（事業関連）` は**事業関連税に限定**し、所得税・住民税・国保・国民年金をこの項目へ自動振分しない。
- UIの `国民健康保険・国民年金` は、内部では `SOCIAL_INSURANCE_NHI` と `SOCIAL_INSURANCE_PENSION` に分割できるよう、詳細種別を必須化する。
- 現行の選択肢にない生命保険料・地震保険料等は、申告控除台帳から登録可能とする。支出画面に選択肢を追加するかは別途UI判断とする。

## 13. 申告控除台帳・データモデル（追加合意）

```text
tax_deduction_record
  id, fiscal_year, deduction_type
  source_transaction_id nullable
  paid_date, payer, insured_person_or_beneficiary
  paid_amount, eligible_amount nullable, calculated_deduction_amount nullable
  evidence_id nullable, notes
  status(CANDIDATE|VERIFIED|APPLIED|INELIGIBLE)
  reviewed_at nullable, applied_return_id nullable

transaction additional fields
  settlement_date nullable
  settlement_status(UNSETTLED|PARTIALLY_SETTLED|SETTLED)
  business_pl_effect(NONE|REVENUE|EXPENSE|COGS)
  deduction_candidate_type nullable
  settlement_reference_id nullable
```

- `paid_amount` と `calculated_deduction_amount` は別値。生命保険料等は控除上限・算式に従う。
- 同一支払に対する経費算入と所得控除の二重計上を検知・禁止する。
- `source_transaction_id` は任意。個人資金からの支払は仕訳なしで控除候補を登録できる。
- 控除候補は自動的に申告確定しない。`VERIFIED` で証憑・支払年・対象者・制度要件を確認し、`APPLIED` で申告版と紐付ける。
- 控除台帳の修正・取消は履歴を保持し、申告書の再計算に反映する。税制の限度額・適用要件は**年度別ルール**として実装し、固定値をハードコードしない。

## 15. 確定申告計算パイプライン・禁止事項（追加合意）

```text
  → 所得控除（社会保険料、生命保険料、地震保険料等）
  → 課税所得・税額計算
  → 税額控除、源泉徴収税額、予定納税額等を反映
= 申告納税額等
```

**禁止事項:**
- `事業主貸` の金額を売上高・事業所得から直接控除すること。
- `事業主借` を売上高へ加算すること。
- 国保・国民年金・個人生命保険料・所得税を必要経費として自動仕訳すること。
- `租税公課` を一律に事業主貸とすること、または全税目を必要経費とすること。
- 所得控除の支払額をそのまま控除額とみなすこと。
- 未決済取引を決済済みと偽って計上すること。
- 事業主貸・事業主借の発生をもって所得控除の適用を自動確定すること。

**運用上の留意点:** 本仕様は所得税の青色申告を主対象とする。実際の控除適用、経費算入、消費税処理、保険・補助金の税務上の扱いは、対象年の法令・国税庁様式・証憑に照らして検証する。
