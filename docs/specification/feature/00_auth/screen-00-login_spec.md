## 画面概要
ログイン画面。メールアドレスとパスワードの入力フォームを表示し、認証処理を行う。ログイン成功時はホーム画面へ遷移、失敗時はエラーメッセージを表示する。
未登録ユーザー向けの導線として新規登録画面へのボタンも提供する。

- **JSP ファイル**: `Auth/login.jsp`
- **URL パス**: `/login`
- **HTTP メソッド**: GET（表示）/ POST（ログイン送信）
- **認証方式**: メールアドレス + パスワード（`app_user.email` / `app_user.password_hash`）

### 画面レイアウト

- `screen-image/00_auth/screen-00-login_image.png` を基に、左側のサービス紹介と右側のログインカードを配置する。
- ロゴ、背景の波形、デスク・ノートPCのイラスト、入力欄アイコンは `css/auth/` の自作SVGを使用し、外部サービスから取得しない。
- 幅1279px以下は紹介エリアを省略し、フォームを優先した1カラム表示とする。
- ログインカードはフッターを除いたコンテンツ領域内で上下中央に配置する。上部にはPCで24px以上、モバイルで12〜16px以上の余白を確保する。
- 表示領域の高さに応じてカード・文字・余白・入力欄を縮め、通常の初期表示を1画面に収める。高さ900px以下・760px以下およびモバイルでは段階的にコンパクト化する。エラー表示や文字拡大で内容が増えた場合は自然な縦スクロールを許可し、操作項目を隠さない。
- パスワードの表示切替、入力エラー、ログイン状態保持、新規登録への遷移は既存処理を維持する。ログイン状態保持は初期状態では未選択。
- パスワード再設定・利用規約・プライバシーポリシー・お問い合わせの未実装リンクは、準備中の通知を表示する。機能や文書の提供済みを意味しない。

## API仕様

### `GET /login`

- 目的: ログイン画面表示
- レスポンス: `200 OK`（JSPレンダリング）

### `POST /login`

- 目的: 認証処理実行
- リクエスト（Form）

| 項目 | 型 | 必須 | 説明 |
|------|----|------|------|
| email | string | ○ | メールアドレス |
| password | string | ○ | 平文パスワード（受信後に保持しない） |
| rememberMe | boolean | - | ログイン状態保持 |

- 正常時レスポンス
  - `302 Found` でホーム画面（`/home`）へリダイレクト
- 異常時レスポンス
  - 認証失敗: `401 Unauthorized`
  - 入力不正: `400 Bad Request`
  - システムエラー: `500 Internal Server Error`

---

## バックエンド検証仕様

- メールアドレスに一致するユーザーを `app_user.email` で検索する。
- パスワードは `app_user.password_hash` と照合し、平文保存は行わない。
- `app_user.status` が `active` の場合のみログイン許可とする（`inactive` / `deleted` は拒否）。
- 認証失敗時のメッセージは「メールアドレスまたはパスワードが正しくありません。」に統一し、存在有無を露出しない。
- 連続失敗時の制限（レート制限/一時ロック）はセキュリティ検証計画 `T-003` の対象として実装・検証する。

---

## セッション管理仕様

- ログイン成功時にセッションを新規発行する。
- 「ログイン状態保持」ON時は通常セッションより長い有効期限を適用する。
- ログイン状態保持トークン/セッションIDは `HttpOnly` / `Secure` / `SameSite` 属性付きCookieで管理する。
- ログアウト、権限変更、アカウント無効化時は該当セッションを失効する。

---

## 監査・ログ

- ログイン成功/失敗を監査ログへ記録する。
- 記録項目: 実行日時、ユーザー識別子（可能な範囲）、送信元情報、結果（成功/失敗）。
- ログにパスワード、トークン、Cookie値を出力しない。
- 本仕様のログ要件は `docs/sequrity/security-test-plan.md` の `T-016` を満たす前提で実装する。

## バリデーションチェック（フロント）仕様

### ログインフォーム

| 項目 | チェック内容 | エラーメッセージ |
|------|------------|----------------|
| メールアドレス | 未入力 | メールアドレスを入力してください。 |
| メールアドレス | 正規表現 `^[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Za-z]{2,}$` | メールアドレスは正しい形式で入力してください。 |
| パスワード | 未入力 | パスワードを入力してください。 |
| パスワード | 8〜72文字の範囲外 | パスワードは8〜72文字で入力してください。 |

---

## バリデーションチェック（バックエンド）仕様

| 項目 | チェック内容 | エラー応答 |
|------|------------|----------|
| email | 未入力/形式不正 | `400 Bad Request` |
| password | 未入力/8〜72文字外 | `400 Bad Request` |
| 認証情報 | email + password 不一致 | `401 Unauthorized` |
| ユーザー状態 | `status != active` | `401 Unauthorized` |

## DB関連注記

- 参照テーブル: `app_user`
- 参照カラム: `email`（UNIQUE）, `password_hash`, `status`
- `password_hash` はハッシュ値のみを保存し、平文パスワードは保持しない。
- `status` は `active` / `inactive` / `deleted` を取り得る。
