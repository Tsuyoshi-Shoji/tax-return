## 画面概要

支出データの新規登録・編集を行う画面。通常モードと月間登録モードを同一画面内で切り替えて利用する。通常モードでは単票登録、月間登録モードでは複数レコードを一括登録できる。区分を選択すると動的に項目セレクトボックスが切り替わる。家事按分チェックを入れると、設定画面の按分率を使って経費対象金額をプレビュー表示する。100,000,000円以上の入力時は確認モーダルを表示する。

- **JSP ファイル**: `Expense/expense.jsp`
- **URL パス**: `/expense`
- **HTTP メソッド**: GET（表示）/ POST（登録・更新）

### 画面モード

| モード | 説明 | 画面扱い |
|------|------|------|
| 通常モード | 1件ずつ支出を登録・編集する既存モード | 支出登録画面内の表示モード |
| 月間登録モード | 月間の支出を複数行まとめて登録するモード | 支出登録画面内の表示モード（別画面ではない） |

### 画面イメージ

- 通常モード: 既存 `screen-05-expense-register.png`（従来仕様）
- 月間登録モード: `screen-05-expense-register_monthlyMode.png`

## 月間登録モード仕様（同一画面）

### 画面概要

月間登録モードは、支出登録画面内で切り替えて利用する一括登録モードである。1行を1件の支出として扱い、複数行をまとめて送信する。新規表示時は初期行を表示し、利用者の操作で入力行を追加する。

### 月間登録モードの画面項目一覧

| 項目名 | 項目 ID / name | 種別 | 必須 | 説明 |
|------|----------------|------|------|------|
| モード切替（通常/月間） | `entry-mode` | トグル/タブ | ○ | 画面遷移なしでモードを切替。`monthly` 選択時に月間登録セクションを表示 |
| 月間対象年月 | `target-month` | 月入力 (`YYYY-MM`) | ○ | 登録対象の年月。各行の日付はこの年月内のみ許可 |
| 行追加（5件）ボタン | `button-add-5-rows` | ボタン | ○ | クリックごとに入力行を5行追加 |
| 行削除ボタン | `button-remove-row` | ボタン | - | 対象行を削除（最低1行は維持） |
| 一括クリアボタン | `button-clear-monthly` | ボタン | ○ | 全行入力とエラー表示をクリア |
| 一括登録ボタン | `button-register-monthly` | 送信ボタン | ○ | 有効な全行をサーバーへ一括送信 |

### 月間登録モードの明細行項目

| 項目名 | 項目 ID / name | 種別 | 必須 | 説明 |
|------|----------------|------|------|------|
| 行番号 | `row-no` | 表示 | ○ | 1始まりで連番表示 |
| 区分 | `rows[i].expense-type` | ラジオ/セレクト | ○ | 経費 / 仕入 / その他 |
| 支出項目 | `rows[i].category` | セレクトボックス | ○ | 区分連動で候補切替（通常モードと同じマスタ） |
| 支出発生日 | `rows[i].date` | 日付入力 | ○ | `target-month` と同年月の日付のみ許可 |
| 金額 | `rows[i].amount` | 数値入力 | ○ | 1円以上。100,000,000円以上は行単位で警告対象 |
| 支払方法 | `rows[i].payment-method` | ラジオ/セレクト | ○ | 現金 / クレジットカード / 電子決済 / 銀行振込 / その他 |
| 申告対象外 | `rows[i].exclude-from-return` | チェックボックス | - | 行単位で設定 |
| 家事按分適用 | `rows[i].home-apportionment` | チェックボックス | - | ON時に行単位で経費対象金額を表示 |
| 経費対象金額 | `rows[i].deductible-amount` | 表示 | - | `amount` と按分率からリアルタイム計算 |
| 支出詳細 | `rows[i].details` | テキスト入力 | ○ | 1〜255文字 |

### 月間登録モードのイベント一覧

| イベント | トリガー | 処理内容 |
|----------|---------|---------|
| モード切替 | `entry-mode` change | 同一画面内で通常モード/月間登録モードを表示切替。未保存内容がある場合は確認ダイアログを表示 |
| 月対象変更 | `target-month` change | 各行 `date` の許容範囲を更新。範囲外エラーを再評価 |
| 行を5件追加 | `button-add-5-rows` click | 入力行を5行追加（5, 10, 15...と増加） |
| 行削除 | `button-remove-row` click | 対象行を削除し、行番号を再採番 |
| 行入力変更 | 各行 input/change | 行単位でエラーをクリアし、必要に応じ按分プレビューを更新 |
| 一括クリア | `button-clear-monthly` click | 全行を初期値に戻し、エラー・警告・集計表示をクリア |
| 一括送信 | `button-register-monthly` click/submit | 全行バリデーション → 高額行チェック → 問題なければ一括送信 |
| 高額確認モーダル「確認して送信」 | click | 高額行を含む内容で送信続行 |

### 月間登録モードのバリデーション（フロント）仕様

| 項目 | チェック内容 | エラーメッセージ |
|------|------------|----------------|
| 月対象年月 | 未入力 | 登録対象月を選択してください。 |
| 月対象年月 | 不正形式 | 登録対象月の形式が不正です。 |
| 明細行 | 0行 | 登録する支出行を1行以上入力してください。 |
| 明細行（各行） | 区分未選択 | 区分を選択してください。 |
| 明細行（各行） | 項目未選択またはマスタ不整合 | 選択された項目がマスタに存在しません。 |
| 明細行（各行） | 支出発生日未入力/不正日付 | 存在する日付を選択してください。 |
| 明細行（各行） | 支出発生日が `target-month` 外 | 支出発生日は対象月内の日付を入力してください。 |

| 明細行（各行） | 支払方法未選択 | 支払方法を選択してください。 |
| 明細行（各行） | 支出詳細が1〜255文字の範囲外 | 支出詳細は1〜255文字で入力してください。 |

### 月間登録モードの送信仕様

- 送信単位は1リクエスト内の複数明細行（配列）とする。
- サーバー側では行単位バリデーションに加え、認可・テナント境界・マスタ整合性を全行で再検証する。
- 1行でもエラーがある場合は全体を失敗として返却し、成功行のみの部分登録は行わない。
- 重複送信対策として、利用者単位の冪等性キーまたはワンタイムトークンを使用する。
