# fixed_asset テーブル定義

## テーブル名
- 物理名: `fixed_asset`
- 論理名: 固定資産台帳

## テーブルの目的
事業用の減価償却資産を管理し、年分ごとの減価償却費・未償却残高を計算する（`DepreciationCalculator`）。計算結果は減価償却仕訳（`journal_entry.source_type = 'DEPRECIATION'`）と青色申告決算書3ページに反映する。

## 計算ルール
- 通常5方式は供用開始月から処分月まで月割り（1円未満切上げ）。有形資産は1円、ソフトウェアは0円まで償却。法定率は耐用年数省令別表七〜十から転記し、逆数による近似はしない。
- 新定額法は2007-04-01以後取得。200％定率は2012-04-01以後、250％定率は2007-04-01〜2012-03-31取得（2012年4〜12月取得は経過措置確認が必要）。定率法は保証額未満となった最初の年の期首残高を改定取得価額として固定し、改定率を適用する。
- 旧定額・旧定率は1953-01-01〜2007-03-31取得。有形の旧定額は取得価額×90％×旧率、旧定率は期首残高×旧率。95％到達翌年以後（2008年分以後）に残額−1円を5年均等償却。旧ソフトウェアは90％・95％制限を適用せず0円まで。
- 中古簡便法は一部経過＝法定月数−経過月数×80％、全部経過＝法定月数×20％を12で割り、最後に年未満切捨て・最低2年。無形・資本的支出を伴う取得は対象外。
- 私用減価は取得価額×90％×（法定年数×1.5の年未満切捨て年数の旧定額率）×私用年数。6か月以上切上げ・未満切捨て、円未満切上げ、取得価額95％（円未満切捨て）を上限とする。事業簿価＝取得価額−私用減価。方式は転用日でなく取得日基準。定額は元の取得価額等、定率は減価控除後残高から償却する。
- 事業専用割合を乗じた額（1円未満切捨て）を必要経費、残額を事業主貸とし、資産科目を直接減額する（直接法）。
- 少額特例：10万円以上、2026-03-31以前取得は30万円未満、2026-04-01以後取得は40万円未満。供用年に全額。年300万円（開廃業年は事業月数按分）上限、適格要件等は年分別に利用者確認する。
- 一括償却：供用年の合計額÷3を円未満切上げ、ID順で端数配分し、最終年に残額調整。売却・除却後も3年償却を継続する。
- 年分別の検証は `DepreciationRules`、利用者の適用根拠・特例等確認は `tax_return_input` に保存する。未確認・対象外時はCSV出力を抑止する。
- V12で16〜21列を追加する。既存の取得額・方式・計算年数は保持し、法定年数を既存年数（2年以上）から補完する。中古・転用・経過措置は自動付与しない。
- 資本的支出（2007-04-01以後）は親資産と同じ勘定科目・法定耐用年数を使う通常償却の別資産として登録する。旧資産への加算、定率法の合算特例、中古簡便法を使う親資産は対象外。
- 相続・贈与は元の取得日・取得価額・償却方法を維持した資産に、移転日と確認済み簿価をイベントとして記録する。過年度の実績・引継ぎ簿価・承継要件は利用者確認であり、旧方式の5年均等償却中、私用転用や方法変更と重なる履歴は対象外。
- 償却方法変更は年初適用、確認済み期首簿価、承認根拠を必須とし、定額法・200％定率法・250％定率法間に限定する。変更後は入力した期首簿価を新しい償却基礎として計算する。変更承認等の法的適格性は自動判定しない。
- 廃業は通常償却資産を廃業日を含む月まで月割りし、廃業年末の残存簿価を表示して私用転用・譲渡等の別処理を警告する。残額の自動処分・所得税額計算は行わない。
- 建物本体等の未登録科目、1952年以前取得、耐用年数範囲外、旧資産への資本的支出加算、定率法の合算特例、旧方式5年均等中の相続・贈与、その他の特別償却等は未対応。既存履歴が登録条件からの再計算と一致することは利用者が確認する。
